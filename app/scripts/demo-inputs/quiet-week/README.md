`npm run demo:gate` 의 자동 발행 예시(`demo-gate-quiet-week`)에 쓰는 입력이다. **실제 실행 기록이 아니다.**

12일째 열려 있던 이슈 #8 을 도구 기록과 6번 카드에서 뺐다. 남은 열린 이슈는 #11(5일째)뿐이라
`stale_issue`(7일) 문턱 아래이고, 배포 실패 0 · 에러 비교값 없음 · 세 도구 모두 성공이라 기준 넷을 모두 통과한다.
